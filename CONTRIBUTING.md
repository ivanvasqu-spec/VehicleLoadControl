# Guía de Contribución

## 🤝 Cómo Contribuir

Thanks por tu interés en contribuir a **Vehicle Load Control**! Aquí está la guía para contribuir:

### 1. Fork el Repositorio

```bash
git clone https://github.com/TU_USERNAME/VehicleLoadControl.git
cd VehicleLoadControl
```

### 2. Crear una Rama

```bash
git checkout -b feature/tu-feature-name
```

### 3. Hacer Cambios

- Sigue las guías de código en [ARCHITECTURE.md](ARCHITECTURE.md)
- Mantén commits pequeños y descriptivos
- Agrega tests para nuevas funcionalidades

### 4. Commit y Push

```bash
git add .
git commit -m "feat: descripción clara del cambio"
git push origin feature/tu-feature-name
```

### 5. Pull Request

- Abre un PR con descripción clara
- Linkea los issues relacionados
- Espera la revisión del equipo

## 📝 Convenciones de Commits

Usamos [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: agregar nueva funcionalidad
fix: arreglar bug
docs: cambios en documentación
test: agregar o modificar tests
refactor: cambios sin afectar funcionalidad
style: cambios de formato/estilo
ci: cambios en CI/CD
```

## ✅ Checklist Antes de Hacer PR

- [ ] El código compila sin errores
- [ ] Los tests pasan
- [ ] Agregué tests para mis cambios
- [ ] Seguí las guías de código
- [ ] Actualicé la documentación
- [ ] Mi rama está actualizada con `main`

**¡Gracias por contribuir!** 🙏
